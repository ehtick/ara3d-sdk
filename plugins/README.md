# plugins — the Bowerbird plug-in host

The Roslyn command host, its CLI and demo shells, and sample commands. These are **not**
included in NuGet meta-packages. The Revit 2025 add-ins built on Bowerbird, and the
BIM Open Schema exporter, live in bim-open-toolkit under `plugins/`.

| Project | Description |
| --- | --- |
| [Ara3D.Bowerbird](Ara3D.Bowerbird) | Roslyn command compile/run core |
| [Ara3D.Bowerbird.Console](Ara3D.Bowerbird.Console) | CLI runner for Bowerbird commands |
| [Ara3D.Bowerbird.Demo](Ara3D.Bowerbird.Demo) | WinForms demo shell |
| [Ara3D.Bowerbird.TestSamples](Ara3D.Bowerbird.TestSamples) | Sample command projects for tests |
